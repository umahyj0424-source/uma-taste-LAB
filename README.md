# 트레센 취향 연구소 · 트레이너 취향 감정서

좋아하는 우마무스메를 순서대로 3~10명 고르면 캐릭터 프로필과 원본 경주마의 출전 기록을 바탕으로 취향 감정서를 발급합니다.

## 내 컴퓨터에서 열기

ZIP 전체를 같은 폴더에 압축 해제한 뒤 `index.html`을 브라우저로 여세요. 이미지와 데이터가 포함되어 있어 오프라인에서도 캐릭터 선택, 분석, 텍스트 복사, PNG 저장이 가능합니다. 클립보드 직접 쓰기가 제한된 브라우저에서는 직접 복사할 수 있는 창이 열립니다.

## GitHub Pages로 공유하기

1. GitHub 저장소에 **압축을 푼 내용물**을 올립니다. 저장소 첫 화면에서 `index.html`이 보여야 합니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
3. 파일이 있는 브랜치(예: `main`)와 **/(root)**를 선택하고 **Save**를 누릅니다.
4. 배포가 끝나면 Pages에 표시된 주소를 공유합니다. 감정서에서 **결과 링크 복사**를 누르면 같은 순서의 라인업과 트레이너 이름이 열리는 주소를 복사합니다.

빌드 명령, API 키, 로그인, 서버 또는 외부 CDN이 필요하지 않습니다. 선택 사항과 이름은 브라우저에서 처리되며 결과를 공유하면 주소의 # 뒤에 포함됩니다. 로컬 파일에서는 PNG나 텍스트로 결과를 공유할 수 있습니다.

## 데이터 입력과 JSON 갱신

1. 상단 **데이터 관리**를 엽니다. 기본 목록은 원본마 전적이 없는 캐릭터입니다. **각질 미입력**, **프로필 미입력**, **전체 142명**으로 바꿀 수 있습니다.
2. 캐릭터를 고르고 신장, B(가슴)·H(엉덩이)·W(허리), 대표 각질, 총출전·승수, 거리별·주로별 출전 횟수를 입력하고 **캐릭터 기록 저장**을 누릅니다. 둘레가 미상인 경우 비워 두세요. 거리·주로의 미집계 출전은 합계에서 빠질 수 있습니다. 횟수 칸의 빈 값은 0으로 처리합니다.
3. 수정 사항은 현재 브라우저에 보관합니다. **전체 JSON 내보내기**로 142명의 최신 스냅샷을 `database.json`으로 저장하세요. **JSON 가져오기**는 파일 안의 ID별 기록을 교체합니다. 일부 ID만 담은 파일도 가능합니다. 잘못된 값이나 중복 ID가 있으면 파일 전체를 반영하지 않습니다.
4. 모든 방문자의 기본 DB를 갱신하려면 저장소 루트의 **database.json**을 내보낸 파일로 교체하고 커밋하세요. Pages 배포 후 새로고침하면 새 기본 자료가 적용됩니다. 브라우저별로 수정한 필드가 있으면 그 값이 우선합니다. 로컬 파일로 열 때는 내장 자료로 시작하므로, 갱신한 JSON을 한 번 가져오세요.
5. 제공 자료에는 대표 각질이 없습니다. 확인된 도주·선행·선입·추입을 직접 입력하세요. 미입력은 각질 판정에서 제외합니다. 원본마 전적 편집은 집계 수치를 수정합니다. 날짜별 공동 출전 목록은 원본 연대기 자료를 따릅니다.

JSON은 `version: 1` 및 `records` 배열을 사용합니다. 각 기록은 기존 ID와 이름, `height`, `B`, `H`, `W`(양수 또는 null), `starts`, `wins`, `dist`(단거리·마일·중거리·장거리), `surface`(잔디·더트·합성·장애물), `style`(대표 각질 또는 null)을 포함합니다.

## 칭호 문구와 극단값 기준 바꾸기

`title-rules.js`의 B·H·W에는 중앙 문구인 `middle`과, 높은 쪽 `high`·낮은 쪽 `low`의 기준표가 있습니다. 항목 형식은 `[전체 표준편차 단위의 차이, "문구"]`입니다. 예를 들어 W의 low 목록에 `[2.0, "극세 허리"]`를 더하면 W가 전체 평균보다 2 표준편차 이상 낮을 때 적용됩니다. 만족하는 기준 중 가장 높은 값을 선택하므로 다른 칭호 계산 코드를 수정할 필요가 없습니다. `style`에서 각질별 별명을 바꿀 수 있습니다.

## 분석 기준

- **캐릭터 프로필**은 142명입니다. cm로 표시하는 신장과 B/H/W는 항목별로 양수인 수치의 단순 평균을 사용합니다.
- **초기 원본마 기록**은 프로필과 연결되는 134명분입니다. 연결된 기록이 없는 8명은 캐릭터 선택과 프로필 통계에 포함되며, 거리와 주로 계산에서 제외됩니다. 레이스 집계는 제공 자료의 범위를 따릅니다.
- **거리와 주로**는 원본마별 출전 비율을 먼저 구합니다. 선택 순서에 따라 1순위 10점부터 10순위 1점까지 부여해 가중 평균합니다. 출전이 취소·제외된 기록은 사용하지 않습니다. 거리 미상인 출전은 거리 비율에서만 제외합니다.
- 거리 구간은 단거리 1,600m 미만, 마일 1,600~1,800m, 중거리 1,800m 초과~2,400m, 장거리 2,400m 초과입니다. 주로는 잔디, 더트, 합성, 장애물입니다.
- **B/H/W 취향 판정**은 가슴둘레(B), 엉덩이둘레(H), 허리둘레(W)를 따로 비교합니다. 선택한 캐릭터를 같은 비중으로 평균 내고 전체 캐릭터 평균과의 차이를 cm로 표시합니다. 부위마다 수치의 분산이 달라 판정에는 평균 차이를 해당 부위의 전체 모집단 표준편차로 나눈 값을 씁니다. B·H·W 각각에서 중간 문구, ±0.5 이상 문구, ±1.5 이상 극단 문구 중 하나를 골라 조합합니다. 가장 큰 차이는 별도 요약에도 표시합니다. 값이 없거나 기준 분포의 표준편차가 0인 항목은 해당 칭호에서 제외합니다.
- **거리·각질 칭호**에는 최다 거리와 대표 각질을 모두 사용합니다. 대표 각질은 입력된 캐릭터만 대상으로 선택 순위(10점~1점)로 투표합니다. 동률인 거리나 각질은 모두 표기하고 미입력 축은 생략합니다. 아울러 감정서에 각질 입력 인원을 표시합니다.
- **함께 달린 한 장면**은 선택한 원본마 둘 이상이 같은 경주에 출전했을 때 나타납니다. 함께 출전한 원본마 수, GI/G1/JpnI 등급 여부, 이른 날짜 순으로 한 경주를 고릅니다.
- 순위와 백분율은 반올림 전 수치로 계산합니다. 표시값은 소수점 첫째 자리까지 반올림합니다.

## 파일과 출처

`index.html`과 `styles.css`는 화면을 구성합니다. `roster.js`에는 캐릭터 수치·출전 집계와 공동 출전 목록이, `portraits.js`에는 142명의 로컬 이미지가 들어 있습니다. `model.js`에서 칭호와 가중치를, `app.js`에서 선택 화면과 결과 카드 디자인을 수정할 수 있습니다.

원본 자료는 사용자 제공 **UMA-BHW-main**(프로필 수치), **uma-history-chart-main**(출전 기록, 프로필 이미지와 연결표)입니다. 프로필 이미지는 경량 WebP로 변환했고, 경주 기록은 캐릭터 단위로 재집계했습니다. `sources.json`에는 캐릭터별 프로필·원본마·경주 기록 출처를 수록했습니다.

원본 자료가 표시한 Wikipedia 문서 라이선스는 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)입니다. 캐릭터와 일러스트의 권리는 각 권리자에게 있습니다. 이 사이트는 비공식 팬 프로젝트입니다.

- 데이터 관리의 각질 미확인 필터는 자동 판정 불가 캐릭터를 보여줌. 기존 브라우저 로컬 편집은 배포 DB보다 우선하므로 기존 수정값이 있다면 확인 필요.
